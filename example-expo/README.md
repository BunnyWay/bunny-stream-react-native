# Bunny Stream React Native — Expo example

Minimal Expo app that consumes `bunny-stream-react-native` through its config
plugin (`app.plugin.js`). Home screen lists the videos in a library; tapping a
playable row opens a simple `BunnyStreamPlayer` screen.

Requires a development build — **Expo Go is not supported** (the library ships
native code). `android/` and `ios/` are gitignored and regenerated by
`expo prebuild` (Continuous Native Generation).

## Setup

```bash
cp .env.example .env   # fill in EXPO_PUBLIC_BUNNY_ACCESS_KEY / EXPO_PUBLIC_BUNNY_LIBRARY_ID
yarn install           # repo root — links the workspace, builds plugin/build
yarn prebuild          # expo prebuild --clean + pod install
yarn ios               # or: yarn android
```

`yarn start` runs the dev server; open the app inside the installed dev build
(expo-dev-client).
